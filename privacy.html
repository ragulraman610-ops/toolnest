PRIVACY

What happens to your inputs?

This page describes the behavior visible in the current ToolNest site code.

Calculators and word counter

The age, percentage, GST, and EMI calculators, along with the word counter, calculate results in the browser using the values you enter. The current app code does not send these values to a ToolNest application backend or save them in browser storage.

Image tools

The image resizer and compressor read the selected image in the browser and draw the output using a canvas. The current app code does not upload the selected image to a ToolNest application backend. The resulting download is created in the browser.

QR generator and external services

The QR generator sends the text or link you enter to api.qrserver.com in a request for a QR image. Do not enter information into that tool unless you are comfortable sending it to that service. The service's own practices are outside the ToolNest code; consult its current privacy information for details.

The pages also load font stylesheets and font files from Google Fonts (fonts.googleapis.com and fonts.gstatic.com).

Website hosting and your browser

When you open the site, your browser requests its pages and files from the configured web host and makes the external font and, when used, QR-service requests described above. This page does not make claims about what those providers log, retain, or otherwise do with request data; check their current documentation for that information.

The site currently has no login, analytics code, cookie banner, contact form, or ToolNest application backend in its files. This is a description of the current implementation, not a statement about your browser, network, or host provider.

Questions

The Contact page contains a placeholder for the site owner's email. It must be replaced with a real address before it can be used.
